Track 1: Agentic Memory

Problem Statement & Our Solution

The Problem

  • • Amnesiac AI Sessions: Autonomous agents start from zero every session, forgetting constraints and repeating flawed advice.
  • • Context Window Limits: Stuffing entire past transcripts is slow, expensive, and pollutes reasoning with conversational noise.
  • • Knowledge Contradictions: Without centralized fusions, different teammates feed opposing rules to the assistant.
  • • Stale Ephemeral Rules: Temporary directives linger indefinitely, misleading future decisions.

Our Solution: TeamBrain

  • • Multi-Scope Memory Engine: Isolated personal vaults, shared team memory, and project-specific contexts.
  • • Atlas Vector Search: 768-dimensional embeddings recall context associatively via cosine similarity.
  • • Decision Fusions & Conflict Resolution: AI engine synthesizes fragmented notes and flags disagreements for lead resolution.
  • • Automatic TTL & Corrections: MongoDB background TTL indexes expire old notes; past memories can be edited or superseded.

Track 1 Requirements

Difficult Lifecycle Cases (Brief)

1. Correction & Supersession supersededBy

Memory #101 ("Use PostgreSQL") is formally superseded by #204 ("Use MongoDB + Mongoose"). The assistant immediately alters its advice without restarts.

2. Time-Based Expiry (TTL) expiresAt Index

Ephemeral release freeze notes and sprint rules expire automatically via MongoDB Atlas background TTL index without manual pruning.

3. Contradiction & Conflict AI Fusion Engine

When teammates assert opposing technical directions, Decision Fusion groups contradictions by topic; team owners publish definitive resolutions.

4. Deletion & Privacy Scope Hard Purge & RBAC

Personal vaults remain strictly private. Deleting a memory purges it from Atlas vector recall and records an immutable audit log in memory_events.
